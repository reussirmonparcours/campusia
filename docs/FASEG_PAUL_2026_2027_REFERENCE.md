# 9. Vue d'ensemble des 6 spécialités

Le référentiel PAUL donne donc actuellement cette structure pour la **Licence fondamentale FASEG** : ([Université de Lomé][1])

| # | Spécialité                                                 | Mention              |
| - | ---------------------------------------------------------- | -------------------- |
| 1 | **Analyse et Politique Économique (APE)**                  | Sciences Économiques |
| 2 | **Économie du Développement**                              | Sciences Économiques |
| 3 | **Économie Internationale**                                | Sciences Économiques |
| 4 | **Comptabilité, Contrôle Audit (CCA)**                     | Gestion              |
| 5 | **Marketing et Stratégie**                                 | Gestion              |
| 6 | **Organisation et Gestion des Ressources Humaines (OGRH)** | Gestion              |

### Et cela nous donne une information extrêmement intéressante pour MonParcours :

```text
                    FASEG
                      │
          ┌───────────┴───────────┐
          │                       │
  Sciences économiques          Gestion
          │                       │
    ┌─────┼─────┐          ┌──────┼──────┐
    │     │     │          │      │      │
   APE   ED    EI         CCA    M&S   OGRH
```

Avec :

```text
S1 ─────────────── Commun
S2 ─────────────── Commun
                  ↓
              Spécialisation
                  ↓
S3 ─── spécifique
S4 ─── spécifique
S5 ─── spécifique
S6 ─── spécifique
```

C'est **très important pour notre architecture** : nous n'avons probablement pas besoin de dupliquer les cours communs six fois dans la base de données. Nous pourrons avoir une structure académique qui représente les **UE communes**, puis leurs rattachements aux différents parcours.

# 10. Maintenant, pour tes cours

**C'est exactement la prochaine étape que je te recommande.**

Ne m'envoie pas simplement les PDF en vrac.

Nous allons construire progressivement la **Knowledge Base FASEG**.

Par exemple, pour chaque UE :

```text
ECO100C
Introduction à l'économie
│
├── Support officiel / cours 1
├── Support cours 2
├── TD
├── Exercices
├── Annales
└── Autres documents
```

Tu peux donc commencer à m'envoyer **les cours que tu possèdes**, même s'ils sont nombreux.

### Idéalement, commence par le S1 :

* `CPT100C` — Comptabilité de base
* `ECO100C` — Introduction à l’économie
* `ECO101C` — Principes de base de la microéconomie
* `ECO102C` — Principes de base de la macroéconomie
* `ECO103C` — Analyse mathématique
* `ECO104C` — Statistique descriptive
* `ECO205C` — Histoire des faits économiques et sociaux

**Puis S2**, et ainsi de suite.

Tu peux aussi m'envoyer **plusieurs PDF en une seule fois**. Je pourrai les examiner et te dire précisément :

> **UE trouvée → cours correspondant → code → semestre → spécialités concernées → document exploitable / incomplet / doublon.**

Et surtout, **ne t'inquiète pas si tes documents utilisent des intitulés légèrement différents** : nous ne les corrigerons pas arbitrairement. Nous les comparerons au référentiel officiel et conserverons la provenance.

Pour notre future IA, cette traçabilité sera essentielle.
